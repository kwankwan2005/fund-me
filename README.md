# FundMe: Crowd-funding platform

*Literally "Nuôi Tôi" (if you know, you know) project.* 

FundMe is a donation platform designed to connect charitable campaigns with potential donors in a transparent and user-friendly manner. 

FundMe allows registered users to browse active campaigns, make donations, view donation progress, and interact with other donors through social features. Campaign creators can register, launch new campaigns, and manage donation activities in real time.

# Tech-stack
- Vue.js
- Vue Router
- Pinata
- Firebase (Realtime DB + Functions for hosting RESTful API)
